# 📞 911 Emergency Calls Dashboard

This is an interactive Streamlit web application for analyzing 911 emergency call data in Montgomery County in Pennsylvania.

##  Features

- **Incident Heatmap**: Visualizes the density of emergency calls on a map.
- **Accident Reasons by Township**: Bar chart showing causes of emergencies by area.
- **Hourly Emergency Trends**: Line graph of when emergencies typically happen during the day.
- **Call Type Distribution**: Top 20 call titles by frequency.
- **Vehicle Accident Trends**: Monthly trend of vehicle-related accidents in key townships.
- **Fire Map**: Heatmap of all fire-related incidents.
- **Fall Incident Analysis**: Comparison of fall incidents in winter vs. rest of the year.
- **Top Addresses**: Bar chart of addresses with the most reported emergencies.
